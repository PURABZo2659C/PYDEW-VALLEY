📋 PROJECT OVERVIEW

What Is PYDEW VALLEY?

A 2D isometric farming game built with Pygame, inspired by Stardew Valley.

  • Procedurally generated infinite worlds using Perlin noise
  • Isometric rendering with depth sorting
  • Farming: hoe, water, plant, harvest crops (wheat, tomato)
  • Day/night cycle with 4 seasons (28 days each)
  • Weather system with rain and visual effects
  • Shop economy: buy seeds, sell harvested items
  • Crafting: 7 recipes for tools, items, furniture
  • Inventory management with drag-and-drop
  • Save/load system (JSON)
  • Customizable keybindings
  • Pause menu with audio/settings controls
  • Debug overlay (F5) with real-time diagnostics

How to Run

🔄 THE PLAY LOOP

Game Flow

1TITLE SCREENNavigate with W/S or ↑/↓, confirm with ENTER or click. Choose NEW GAME (deletes save), CONTINUE (loads data/save.json), or EXIT.
▼
2WAKE UP — DAY STARTS AT 07:00You spawn at your farm with 9-slot hotbar + bag, energy hearts, and money. Time runs at 10 game-minutes per ~4.2 real seconds.
▼
3FARMING CYCLEThe core repeatable loop — see the chips below. Sleep to grow crops overnight.
▼
4EXPLORE & EARNGather wood/stone/ores, craft, trade with villagers (06:00–20:00), deliver quest items, explore the cave (time frozen inside).
▼
5SLEEP → NEW DAYUse a bed (TMX beds work 22:00–02:00; player-placed bed anytime) → fade transition → crops grow (watered only), weather rolls, season/day advance, auto-save, wake 07:00. Repeat from step 3.
▼
★WIN: HEART OF THE VALLEYComplete all 3 quest pages (3 × 6 deliveries of 64 items) → unlock & craft the Heart of the Valley → place its emblem on the quest board → 3-second impact FX → CREDITS roll.

Farming Cycle (the heart of the loop)

1. TILL — select hoe, aim at soil, ENTER 2. PLANT — select seed, RSHIFT 3. WATER — select bucket, RSHIFT (5 uses) 4. GROW — sleep to advance a day (watered crops only) 5. HARVEST — empty hand, RSHIFT → 1–3 crops + seeds back 6. SELL / CRAFT / DELIVER → upgrade farm, repeat

★ GAME SYSTEMS AT A GLANCE

🎒 Inventory

9-slot hotbar + 9×3 bag. E toggles. Click to move, Shift+click to quick-move, right-click to split, double-click to gather all.

🔨 Crafting

C toggles. Scroll the recipe list; left-click crafts ×1, right-click crafts ×ALL. Closes with ESC.

📜 Quests

Enter the Town Hall board with ENTER. 3 pages × 6 deliveries of 64 items each. Finish all pages to unlock the Heart of the Valley recipe. Arrow keys move the grid, SPACE places the heart emblem.

🧑‍🌾 Villagers & Shop

Press RSHIFT near an NPC (talk radius) between 06:00–20:00. Scroll trades, left-click selects, right-click trades ALL. Close with the ✕ button.

⛏ Cave

Enter via a cave entrance (interaction sprite) — scene swaps through the fade transition. Time freezes inside. Dark overlay + night-vision potions; pickaxe mines ores, axe breaks crates, punch smashes pots. ENTER on the exit lifts you out.

🌍 World

Villages and houses stream in around you — no loading screens. Houses are solid collision blockers; bridges, plaza and river are part of the generated world.

💾 Saving

data/save.json (+ .bak). Auto-saves on sleep/day-end and credits; Save & Quit from the pause menu. NEW GAME deletes the old save.

⏸ Pause Menu

ESC or the HUD MENU button → Resume / Settings / Save / Quit. Settings holds the key-rebinding UI, volume controls, and Reset Defaults.

🏁 Winning

Complete every quest delivery → craft the Heart of the Valley → place it on the quest board → credits roll. That's the ending!

⌨ INPUT LOCK: while an F5 debug widget has focus, all gameplay input is frozen until you release it.

🏃 PLAYER SYSTEM

Movement

  • Speed: 400 px/second
  • 8-directional movement (WASD)
  • Isometric conversion: world_dx=(dir.x+dir.y)·0.5, world_dy=(dir.y−dir.x)·0.5
  • Collision: 3-pass push-out against collision_sprites
  • Hitbox: rect.inflate(−126, −70)

Energy

  • Max: 100 (10 hearts, each = 10 energy)
  • Tool use: 0.5 energy; Watering: 0.3; Planting: 0.3
  • Bread restores 30 energy
  • At 0 energy, tool actions blocked with error sound
  • Restored by food/potions only — not sleep

  • Custom 2D Perlin noise (gradient vectors + Hermite interpolation)
  • Deterministic: seed 12345 → identical worlds
  • 6 independent noise layers

Chunk System

  • Chunk size: 1024 px (8×8 tiles)
  • Active radius: 3 chunks (7×7 grid = 49 chunks)
  • Generation radius: 4 chunks
  • Chunks generated on-demand, removed when out of range

🌧 WEATHER SYSTEM

  • Weather determined randomly each day: 30% chance of rain (randint(0,10) > 7)
  • Rain lasts 1–3 days
  • Rain automatically waters all hoed soil
  • Rain state saved and persisted across sessions

Visual Effects

  • Falling rain drops — moving particles, speed 200–250 px/s
  • Floor splash particles — static, random positions
  • Rain sprites from graphics/rain/drops/ and graphics/rain/floor/
  • Sky color overlay tints the scene
  • Darkness overlay appears at night (20:00+)
  • Night-vision potions help visibility at night

⚙ TECHNICAL SPECIFICATIONS

Environment

Language: Python 3.13.14
Engine: Pygame 2.6.1 (SDL 2.28.4)
Display: Full screen
Target FPS: 60

Rendering

Projection: Isometric 2:1
Tile: 128 × 64 px diamond
Tile→screen: x=(gx−gy)·64+64, y=(gx+gy)·32
Chunks: 1024×1024 px, radius 3
Depth sort: (centery+centerx, z)

Rendering Layers (z-order)

z=0 Water — animated water tiles
z=1 Ground — ground tiles
z=2 Soil — hoed soil tiles
z=3 Soil Water — watered soil overlay
z=4 Rain Floor — rain floor splashes
z=5 House Bottom — house lower portion
z=6 Ground Plant — seedling plants
z=7 Main — player, trees, rocks, mature plants
z=8 House Top — house upper portion
z=9 Fruit — apples on trees
z=10 Rain Drops — falling rain drops

💾 SAVE / LOAD SYSTEM

Save path: data/save.json (JSON format) + .bak backup.

Auto-saves On

  • Sleep / day transition
  • Save & Quit from pause menu
  • After credits roll

Saved Data

  • Player position, status, money, energy
  • Full inventory (item_inventory + seed_inventory)
  • Hotbar contents
  • Soil grid state (all cells with flags)
  • Plant data (position, type, age)
  • Weather state (raining, rain_days_left)
  • Sky state (color, night flag)
  • Time (hour, minute, day, season, year)
  • World seed

New Game / Continue

  • NEW GAME — deletes existing save, starts fresh
  • CONTINUE — loads save.json if it exists
